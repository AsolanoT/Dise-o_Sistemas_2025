📘 PROYECTO: ERP TRIBUTARIO (Versión educativa simplificada)

🎯 Objetivo:
Desarrollar un sistema básico ERP tributario que permita la gestión de usuarios, tributos y facturas. El sistema debe contemplar 3 roles definidos y funcionalidades asociadas a cada uno.

🔐 Roles del Sistema:

1. SuperAdmin

   * Accede a todo el sistema sin restricciones.

2. Entidad Pública (por ejemplo: Alcaldía)

   * Genera la factura para el contribuyente, incluyendo:

     * Datos del contribuyente
     * Tipo de tributo
     * Valor
     * Estado de la factura: Activa (A) o Cancelada (C)
   * Puede consultar todas las facturas y cambiar su estado.

3. Contribuyente

   * Puede ser persona natural o persona jurídica.
   * Tiene las siguientes funcionalidades:

     * Registro (con selección de rol)
     * Login (usuario y contraseña)
     * Visualización de sus facturas (tipo de tributo, valor, estado)
     * Actualización de sus datos y actividades tributarias

📄 Funcionalidades clave (según lo indicado por el profesor):

* Registro de usuario con los siguientes campos:

  * Nombre
  * Identificación (tipo y número)
  * Dirección
  * Tipo de tributo asociado (multas, movilidad, predial, industria y comercio)
  * Rol (se selecciona al registrarse)

* Edición y actualización de usuario

* Login con usuario y contraseña

* Generación de factura por parte de la entidad pública con los campos:

  * Rol del contribuyente
  * Tipo de tributo
  * Valor
  * Estado: A (Activa) o C (Cancelada)

* Visualización de factura:

  * El contribuyente ve su(s) factura(s)
  * La entidad puede ver todas las facturas y cambiar su estado

📌 Importante:

* La entidad pública es quien genera y gestiona el estado de la factura (puede marcarla como cancelada o dejarla activa).
* El contribuyente no puede cancelar facturas; solo puede verlas y actualizar sus datos.
* El sistema solo maneja lo estrictamente necesario: registro, edición, login, generación y visualización de facturas.

🗃️ Datos esenciales del sistema:

Usuario

* idUsuario
* nombre
* tipoIdentificación (CC, NIT, etc.)
* númeroIdentificación
* dirección
* tipoContribuyente (persona natural / jurídica)

Factura

* idUsuario (FK al contribuyente)
* tipoTributo (multas, movilidad, predial, etc.)
* valor
* estado (A / C)
* generadaPor (FK a entidad pública)

	REGSITRO DE TIPO DE TRIBUTOS
La base de cálculo es fundamental en el cálculo de impuestos porque determina sobre qué monto se aplica la tarifa tributaria. Es como la base sobre la cual se calcula cuánto debes pagar.
Por ejemplo:
- Si una persona tiene ingresos anuales de $72.000.000 COP, ese monto es la base de cálculo para el Impuesto de Renta.
- Si una empresa vende productos por $10.000.000 COP, esa cifra es la base de cálculo para el IVA.
- Si una persona posee un inmueble valorado en $250.000.000 COP, ese es el valor base sobre el que se cobra el Impuesto Predial.
La base de cálculo varía dependiendo del tipo de tributo y la actividad económica del contribuyente. Es el punto de partida para determinar cuánto impuesto debe pagarse.

Exactamente. En la tabla de tipo de tributo, la base de cálculo no debería ser un valor fijo, porque depende de cada contribuyente y su situación específica.
En lugar de un número estático, podrías incluir una descripción general de cómo se calcula la base para cada tipo de impuesto. Por ejemplo:
- Para el IVA, la base de cálculo es el valor de venta de bienes y servicios.
- Para el Impuesto de Renta, es el ingreso neto anual de la persona o empresa.
- Para el Impuesto Predial, es el avalúo catastral del inmueble.
- Para el ICA, es el total de ingresos brutos generados por la actividad comercial.
Así, cuando el sistema procese los datos de un contribuyente, calculará la base de acuerdo con sus valores específicos. ¿Quieres que te ayude a estructurar mejor la tabla para reflejar esto?

Contexto General de la Base de Cálculo
Cada tributo tiene una fórmula específica para determinar la base de cálculo, dependiendo de la naturaleza del impuesto. Algunas bases comunes incluyen:
- Ventas o Ingresos Brutos 🛒
- Aplicable en impuestos como el IVA o tributos sobre ingresos empresariales.
- Ejemplo: Si una empresa factura $50,000 en un mes, ese monto puede servir como base para calcular el tributo.
